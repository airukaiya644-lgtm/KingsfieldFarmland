# Kingsfield website — Raahiz Properties enquiries

## Open the website
Unzip the entire package, then open `index.html`. Keep `assets/`, `styles.css`, `app.js` and `privacy-policy/` together. There is no installation or build step.

## Included
- Responsive homepage with your four supplied creatives.
- Amenities, location, FAQ and site-visit section.
- Click-to-call contact links for +91 8892750037.
- Site-visit form that prepares a WhatsApp enquiry. The visitor must press Send in WhatsApp. This is not a backend lead database or an appointment confirmation system.
- A separate Privacy Policy page at `privacy-policy/index.html`.
- Gallery lightbox, mobile navigation and reduced-motion support.

## Publish and obtain the privacy URL
Upload the complete site folder to a public static HTTPS host, or import it into Emergent. Keep the privacy-policy directory intact. The deployed policy will be at the real deployed domain followed by `/privacy-policy/` (on hosts with directory-index support), or `/privacy-policy/index.html`.

This ZIP is not a live deployment. Do not put a sandbox link, local file path or invented domain into Meta. After publication, open the policy in a signed-out/private browser and verify that the page is accessible without login. Copy that exact HTTPS URL into Meta. Link label: “View our Privacy Policy”.
